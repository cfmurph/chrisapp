GigTrack — Interactive Preview

This is a browser mockup of the real SwiftUI/SwiftData iOS app, standing in because this sandbox has no Xcode/iOS Simulator. It mirrors the same screens, data model, and flows as the code in GigTrack/GigTrack/. Data is saved to your browser's local storage.

  • 🧾 Add a receipt (photo, vendor, amount, category)
  • 📄 Create clients & invoices, mark paid, share a PDF preview
  • ⏱️ Add crew, start/stop a live timer, edit logged hours
  • 🚗 Log a trip and see the driving cost calculated
